Écoute : deux façons de parcourir un graphique

Données inventées : kilos de pommes et de poires vendus par un verger fictif, de janvier à juin.

Motif A : le graphique est une seule zone, une région annonce le point

Tab jusqu'au graphique, puis flèches gauche/droite (point), haut/bas (série), Début/Fin.

Motif B : chaque point est un élément de liste qui prend le focus

Tab jusqu'au graphique, puis les mêmes touches. Le navigateur VoiceOver (VO + flèches) parcourt aussi les points.
