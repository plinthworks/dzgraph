La borne basse de l'axe, fixée.

<OptionFacts axis="min" />

## Ce qu'elle fait

Sans elle, un axe de valeurs s'ajuste aux données et arrondit ses bouts vers l'extérieur, aux graduations ; les
colonnes, les barres et les aires gardent toujours zéro. Un `min` est gardé tel quel, sans arrondi ; l'autre bout
reste arrondi à une graduation, et les graduations tombent à l'intérieur. Un `min` au-dessus de toutes les valeurs est
signalé (`invalid-option`) et laissé de côté. Un zoom reste dans les bornes.

Sur un axe de temps, une borne est un nombre de millisecondes, une date-heure ISO avec son décalage, ou un
jour (`'2026-03-01'`, son minuit dans le [fuseau](../zone/) de l'axe) ; une date-heure sans décalage est signalée
`ambiguous-instant` et laissée de côté. Sur un axe logarithmique, une borne nulle ou négative est signalée
(`invalid-option`) et laissée de côté. Un `min` supérieur ou égal à `max` est signalé sur `min`, et les deux sont
laissés de côté. Un axe de catégories n'a pas de bornes : elles sont signalées (`unknown-option`).

## Exemple

<CodeTabs>
<Fragment slot="ts">

```ts
import { line } from '@dzgraph/core';
import { chart } from '@dzgraph/dom';

chart(document.getElementById('visits')!, {
  title: { text: 'Visiteurs par jour (inventés)' },
  yAxis: { min: 0 },
  series: [{ type: 'line', id: 'visits', name: 'Visiteurs', data: [64, 71, 69, 78, 87, 82, 75] }],
}, { types: [line] });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { line, type ChartOptions } from '@dzgraph/core';
import { DzChart } from '@dzgraph/angular';

@Component({
  selector: 'app-visits',

export class Visits {

  readonly options: ChartOptions = {
    title: { text: 'Visiteurs par jour (inventés)' },
    yAxis: { min: 0 },
    series: [{ type: 'line', id: 'visits', name: 'Visiteurs', data: [64, 71, 69, 78, 87, 82, 75] }],
  };
}
```
