L'axe de l'autre côté du tracé.

<OptionFacts axis="opposite" />

## Ce qu'elle fait

Un axe x passe en haut au lieu d'en bas ; un axe y à la fin du sens de lecture au lieu de son début : à droite
dans une page de gauche à droite, à gauche dans une page de droite à gauche. Cela vaut quelle que soit l'orientation :
avec des barres, l'axe x est vertical et `opposite` le passe du côté de la fin.

Son usage courant est un second axe de valeurs. Les graduations du second tombent alors sur les lignes de grille du
premier (autant de graduations, son propre pas rond) : une seule grille sert aux deux, et seul le premier la trace.

```ts
import { column, line } from '@dzgraph/core';
import { chart } from '@dzgraph/dom';

chart(document.getElementById('rain')!, {
  xAxis: { scale: 'category', categories: ['janv.', 'févr.', 'mars', 'avr.', 'mai', 'juin'] },

  series: [
    { type: 'column', id: 'rain', name: 'Pluie', yAxis: 'rain', data: [62, 48, 51, 44, 57, 39] },
    { type: 'line', id: 'heat', name: 'Douceur', yAxis: 'heat', data: [4, 6, 9, 13, 17, 21] },
  ],
}, { types: [column, line] });
```

```ts
import { Component } from '@angular/core';

      { type: 'column', id: 'rain', name: 'Pluie', yAxis: 'rain', data: [62, 48, 51, 44, 57, 39] },
```
