L'axe tracé de sa fin vers son début.

<OptionFacts axis="reversed" />

## Ce qu'elle fait

Les valeurs croissent vers l'origine : sur un axe y, vers le bas (une profondeur, un rang où 1 est le meilleur) ;
sur un axe x, de la fin du sens de lecture vers son début. Toutes les autres règles restent : bouts arrondis,
graduations, zéro gardé pour les colonnes et les aires, qui poussent alors depuis le haut. Sur un axe logarithmique,
c'est pareil.

## Exemple

<CodeTabs>
<Fragment slot="ts">

```ts
import { area } from '@dzgraph/core';
import { chart } from '@dzgraph/dom';

chart(document.getElementById('lake')!, {
  title: { text: 'Un lac inventé, traversé' },
  xAxis: { title: 'Distance au bord (m)' },
  yAxis: { title: 'Profondeur (m)', reversed: true },
  series: [{ type: 'area', id: 'depth', name: 'Profondeur', data: [[0, 0], [20, 3.5], [40, 8.2], [60, 12.4], [80, 9.1], [100, 2.6], [120, 0]] }],
}, { types: [area] });
```

  };
}
