Le détail de chaque point : un clic sur le point le montre à sa place.

<OptionFacts series="drilldown" />

## Ce qu'elle fait

`{ details: { [clé]: séries[] } }` donne le détail de chaque point par sa [clé](../data/) ; `{ load: (point) =>
Promise<séries[]> }` le charge à la demande. Un point qui a un détail montre une main sous le pointeur, et les lecteurs
d'écran entendent « détail disponible ». Un clic, ou Entrée, remplace les séries du graphique par celles du détail ;
un fil d'Ariane au-dessus du tracé revient en arrière, comme Retour arrière et Alt + ←, et le niveau revient tel qu'il
était. L'événement `drill` donne le chemin des clés, et la vue le garde. Un chargement qui échoue, ou dure plus de
10 s, le dit et propose de réessayer.

Autre chose qu'exactement un de `details` (chacun une liste de séries) ou `load` (une fonction) est signalé par
`invalid-option` (`series[i].drilldown`). Sans la fonction `drilldown`, l'option est signalée (`missing-module`) et
aucun point n'a de détail.

<Fragment slot="ts">

```ts
import { column } from '@dzgraph/core';
import { chart, drilldown } from '@dzgraph/dom';

const c = chart(
  document.getElementById('orchard')!,
  {
    xAxis: { scale: 'category', categories: ['Pommes', 'Poires'] },
    series: [
      {
        type: 'column',
        id: 'fruit',
        name: 'Cagettes',
        data: { y: [52, 31], key: ['apples', 'pears'] },
        drilldown: {
          details: {
            apples: [{ type: 'column', id: 'apples', name: 'Pommes', data: [['Gala', 22], ['Russet', 17], ['Bramley', 13]] }],
            pears: [{ type: 'column', id: 'pears', name: 'Poires', data: [['Comice', 19], ['Conference', 12]] }],
          },
        },
      },
    ],
  },
  { types: [column], features: [drilldown] },
);
c.on('drill', (e) => console.log(e.path));
```

```ts
import { Component } from '@angular/core';
import { column, type ChartOptions } from '@dzgraph/core';
import { drilldown } from '@dzgraph/dom';
import { DzChart } from '@dzgraph/angular';

@Component({
  selector: 'app-orchard',
  imports: [DzChart],
  template: `<dz-chart style="block-size: 300px" [options]="options" [types]="types" [features]="features" />`,
})
export class Orchard {
  readonly types = [column];
  readonly features = [drilldown];
  readonly options: ChartOptions = {
    xAxis: { scale: 'category', categories: ['Pommes', 'Poires'] },
    series: [
      {
        type: 'column',
        id: 'fruit',
        name: 'Cagettes',
        data: { y: [52, 31], key: ['apples', 'pears'] },
        drilldown: {
          details: {
            apples: [{ type: 'column', id: 'apples', name: 'Pommes', data: [['Gala', 22], ['Russet', 17], ['Bramley', 13]] }],
            pears: [{ type: 'column', id: 'pears', name: 'Poires', data: [['Comice', 19], ['Conference', 12]] }],
          },
        },
      },
    ],
  };
}
```
