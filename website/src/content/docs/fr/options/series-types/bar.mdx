Des colonnes en travers : le graphique devient horizontal.

<OptionFacts seriesType="bar" />

## Ce qu'il dessine

Les barres sont des [colonnes](../column/) en travers. Les catégories descendent depuis le haut ; les valeurs
grandissent dans le sens de lecture, depuis la gauche de gauche à droite, depuis la droite de droite à gauche. L'axe x
est vertical et l'axe des valeurs horizontal, mais ils gardent leurs noms : les catégories restent `xAxis`, les
valeurs `yAxis`. Les lignes, aires et nuages du même graphique suivent l'orientation des barres ; des colonnes y sont
signalées (`mixed-orientation`).

`stack` fonctionne comme sur les colonnes.

<Fragment slot="ts">

```ts
import { bar } from '@dzgraph/core';
import { chart } from '@dzgraph/dom';

chart(
  document.getElementById('jars')!,
  {
    xAxis: { scale: 'category', categories: ['Prune', 'Coing', 'Cerise'] },
    series: [{ type: 'bar', id: 'jars', name: 'Pots vendus', data: [1250, 860, 2240] }],
  },
  { types: [bar] },
);
```
