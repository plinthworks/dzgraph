Un secteur avec un trou, qui contient le total.

<OptionFacts seriesType="donut" />

## Ce qu'il dessine

Tout ce que fait un [secteur](../pie/), `others` compris, avec un trou au milieu. `hole` est sa taille en part du
rayon, de 0 à 0,9 ; toute autre valeur est signalée (`invalid-option`, `series[i].hole`). Le trou montre le total et
le mot « Total » ; `center: { label, value }` y écrit vos propres mots (deux chaînes), et `center: false` le laisse
vide. Un `center` d'une autre forme donne `invalid-option` (`series[i].center`).

## Exemple

<CodeTabs>
<Fragment slot="ts">

```ts
import { donut } from '@dzgraph/core';
import { chart } from '@dzgraph/dom';

chart(
  document.getElementById('seeds')!,
  {
    series: [
      {
        type: 'donut',
        id: 'seeds',
        name: 'Graines',
        hole: 0.5,
        center: { label: 'Sachets', value: '1 400' },
        data: [['Carottes', 420], ['Betteraves', 260], ['Laitues', 380], ['Radis', 190], ['Épinards', 150]],
      },
    ],
  },
  { types: [donut] },
);
```
