Une ligne dont la surface est remplie jusqu'à zéro.

<OptionFacts seriesType="area" />

## Ce qu'il dessine

Une aire est une [ligne](../line/) dont la surface est remplie jusqu'à zéro, translucide, la ligne par-dessus ; sous
zéro, elle remplit jusqu'à zéro. Son axe contient toujours zéro. `marker` fonctionne comme sur une ligne.

`stack` empile l'aire sur les autres aires de la même pile : `true` est la pile nommée `default`, une chaîne en nomme
une autre. Les aires s'empilent par x égaux, un point manquant y comptant pour zéro ; l'axe des valeurs englobe les
piles. `stacking: 'percent'` sur l'axe y fait de chaque pile des parts de son total. Les aires empilées ne sont pas
décimées. Un `stack` qui n'est ni un booléen ni une chaîne non vide donne `invalid-option` (`series[i].stack`), de
même qu'une pile sur un axe logarithmique.

```ts
import { area } from '@dzgraph/core';
import { chart } from '@dzgraph/dom';

chart(
  document.getElementById('visits')!,
  {
    xAxis: { scale: 'category', categories: ['lun.', 'mar.', 'mer.', 'jeu.', 'ven.'] },
    series: [
      { type: 'area', id: 'greenhouse', name: 'Serre', stack: true, data: [42, 46, 61, 58, 70] },

    ],
  },
  { types: [area] },
);
```
