Des boutons pour les durées usuelles : un mois, trois mois, l'année en cours, un an, tout.

<OptionFacts chart="rangeButtons" />

## Ce qu'elle fait

Au-dessus du tracé, au début du sens de lecture : « 1 m », « 3 m », « Début d'année », « 1 an », « Tout » (dans la
langue du graphique). Chacun montre une durée qui finit au dernier point, comptée sur le calendrier et le fuseau de
l'axe : un ou trois mois en arrière, depuis le 1er janvier de l'année du dernier point, un an en arrière ; « Tout »
revient à toutes les données. Un bouton dont la durée dépasse les données est désactivé ; celui qui correspond à la
plage visible est enfoncé.

Ils viennent par défaut avec le [`navigator`](../navigator/) sur un axe de temps ; `false` les retire, `true` les
montre sans le navigateur. Ils demandent la fonction [`navigatorStrip`](../../features/navigator-strip/)
(`missing-module` sur `rangeButtons` sans elle). Ce sont des durées : hors d'un axe de temps, ils sont signalés
(`not-available` sur `rangeButtons`, détail `not-time`) et laissés de côté. Une autre valeur qu'un booléen est
`invalid-option`.

## Exemple

<CodeTabs>
<Fragment slot="ts">

```ts
import { line } from '@dzgraph/core';
import { chart, timeAxis, navigatorStrip } from '@dzgraph/dom';

chart(
  document.getElementById('range-buttons')!,
  {
    rangeButtons: true,
    xAxis: { scale: 'time', zone: 'UTC' },
    series: [{ type: 'line', id: 'level', name: 'Niveau de la mare (cm)', data: [['2025-06-01', 38], ['2025-12-01', 47], ['2026-03-01', 52], ['2026-04-01', 49]] }],
  },
  { types: [line], features: [timeAxis, navigatorStrip] },
);
```

<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { line, type ChartOptions } from '@dzgraph/core';
import { timeAxis, navigatorStrip } from '@dzgraph/dom';
import { DzChart } from '@dzgraph/angular';

@Component({
  selector: 'app-range-buttons',
  imports: [DzChart],
  template: `<dz-chart style="block-size: 300px" [options]="options" [types]="types" [features]="features" />`,
})
export class RangeButtonsChart {
  readonly types = [line];
  readonly features = [timeAxis, navigatorStrip];
  readonly options: ChartOptions = {
    rangeButtons: true,
    xAxis: { scale: 'time', zone: 'UTC' },
    series: [{ type: 'line', id: 'level', name: 'Niveau de la mare (cm)', data: [['2025-06-01', 38], ['2025-12-01', 47], ['2026-03-01', 52], ['2026-04-01', 49]] }],
  };
}
```
