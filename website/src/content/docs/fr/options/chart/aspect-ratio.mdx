Largeur ÷ hauteur, pour un élément sans hauteur propre.

<OptionFacts chart="aspectRatio" />

## Ce qu'elle fait

Le graphique prend la taille de son élément et la suit. Sa hauteur vient de l'élément — une hauteur en CSS, une case
de grille ou de flex —, jamais de son contenu, si bien que le graphique ne saute pas quand ses données changent. Quand
l'élément n'a pas de hauteur propre, le graphique prend sa largeur et ce rapport : `2` est deux fois plus large que
haut.

Une valeur qui n'est pas un nombre fini positif est signalée (`invalid-option` sur `aspectRatio`) et la valeur par
défaut est prise.

<Fragment slot="ts">

```ts
import { area } from '@dzgraph/core';
import { chart } from '@dzgraph/dom';

chart(
  document.getElementById('aspect-ratio')!,
  {
    aspectRatio: 3,
    series: [{ type: 'area', id: 'rain', name: 'Pluie (mm)', data: [12, 18, 9, 22, 30, 14, 8] }],
  },
  { types: [area] },
);
```
