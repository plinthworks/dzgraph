De droite à gauche, l'axe x qui va lui aussi de droite à gauche.

<OptionFacts chart="mirror" />

## Ce qu'elle fait

Seuls les graphiques de droite à gauche sont concernés ([`dir`](../dir/) `'rtl'`, ou le sens de l'élément). Par
défaut, leur axe x va toujours de gauche à droite : le temps et les catégories vont comme les nombres. `true` le
retourne : la première catégorie, le temps le plus ancien, est à droite. L'axe des valeurs, le titre et la légende
suivent le sens de lecture dans les deux cas.

De gauche à droite, `mirror` ne change rien. Une autre valeur qu'un booléen est signalée (`invalid-option` sur
`mirror`).

## Exemple

<CodeTabs>
<Fragment slot="ts">

```ts
import { column } from '@dzgraph/core';
import { chart } from '@dzgraph/dom';

chart(
  document.getElementById('mirror')!,
  {
    dir: 'rtl',
    mirror: true,
    xAxis: { scale: 'category', categories: ['Semaine 1', 'Semaine 2', 'Semaine 3', 'Semaine 4'] },
    series: [{ type: 'column', id: 'jars', name: 'Pots', data: [18, 24, 21, 30] }],
  },
  { types: [column] },
);
```

  readonly options: ChartOptions = {

    series: [{ type: 'column', id: 'jars', name: 'Pots', data: [18, 24, 21, 30] }],
  };
}
