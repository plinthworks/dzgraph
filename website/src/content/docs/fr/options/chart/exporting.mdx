Les réglages des exports : le nom du fichier, les couleurs des images, les séparateurs du CSV.

<OptionFacts chart="exporting" />

## Ce qu'elle fait

Le graphique s'exporte par ses méthodes — `exportSvg()`, `exportPng()`, `exportCsv()`, `download()`, `print()` — et
par le [`menu`](../menu/) du lecteur. Cette option donne leurs réglages par défaut :

- `filename` : le nom du fichier téléchargé, sans son extension. Par défaut les lettres, chiffres et tirets du titre,
  sinon « graphique » dans la langue du graphique.
- `theme` : `'light'` ou `'dark'` pour les images (SVG, PNG). Par défaut elles gardent les couleurs de l'écran : une
  page sombre s'exporte sombre.
- `csv.locale` : `true` écrit des points-virgules entre les cellules et une virgule décimale là où la langue du
  graphique en écrit une (comme l'attend un tableur français). Par défaut le CSV est universel : virgules et points.

Les exports demandent la fonction [`exporting`](../../features/exporting/). L'option est lue sans elle, mais les
méthodes ne font alors rien et signalent `missing-module` sur `exporting`. Autre chose qu'un objet est
`invalid-option` sur `exporting` ; une clé ou une valeur erronée `invalid-option` sur `exporting.<clé>`.

## Exemple

<CodeTabs>
<Fragment slot="ts">

```ts
import { column } from '@dzgraph/core';
import { chart, exporting } from '@dzgraph/dom';

const c = chart(
  document.getElementById('exporting')!,
  {
    title: 'Cagettes cueillies (inventées)',
    exporting: { filename: 'cagettes', theme: 'light', csv: { locale: true } },
    series: [{ type: 'column', id: 'crates', name: 'Cagettes', data: [12, 19, 15, 22, 17] }],
  },
  { types: [column], features: [exporting] },
);

document.getElementById('save')!.addEventListener('click', () => void c.download('png'));
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { column, type ChartOptions } from '@dzgraph/core';
import { exporting } from '@dzgraph/dom';
import { DzChart } from '@dzgraph/angular';

@Component({
  selector: 'app-exporting',
  imports: [DzChart],
  template: `<dz-chart style="block-size: 300px" [options]="options" [types]="types" [features]="features" />`,
})
export class ExportingChart {
  readonly types = [column];
  readonly features = [exporting];
  readonly options: ChartOptions = {
    title: 'Cagettes cueillies (inventées)',
    exporting: { filename: 'cagettes', theme: 'light', csv: { locale: true } },
    series: [{ type: 'column', id: 'crates', name: 'Cagettes', data: [12, 19, 15, 22, 17] }],
  };
}
```
