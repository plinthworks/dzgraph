Chaque nom public de `@dzgraph/angular`, entrée par entrée, avec sa déclaration telle que les types publiés la donnent. Fait depuis [`api/dzgraph-angular.api.txt`](https://github.com/plinthworks/dzgraph/blob/main/api/dzgraph-angular.api.txt), la surface qu’un test empêche de rétrécir d’une version à l’autre ; les [guides](../../guides/data/) et les [pages d’options](../../options/) disent ce que fait chaque nom. Les déclarations sont du code : elles restent en anglais.
