Chaque nom public de `@dzgraph/theme`, entrée par entrée, avec sa déclaration telle que les types publiés la donnent. Fait depuis [`api/dzgraph-theme.api.txt`](https://github.com/plinthworks/dzgraph/blob/main/api/dzgraph-theme.api.txt), la surface qu’un test empêche de rétrécir d’une version à l’autre ; les [guides](../../guides/data/) et les [pages d’options](../../options/) disent ce que fait chaque nom. Les déclarations sont du code : elles restent en anglais.

Importées pour ce qu’elles font, sans nom à elles :

- `@dzgraph/theme/dzgraph.css`
- `@dzgraph/theme/dzgraph.unlayered.css`
- `@dzgraph/theme/dzgraph.scss`

Ce que règlent les feuilles, et comment le changer : [Thème et droite à gauche](../../guides/theming-rtl/).
