import LiveChart from '../../../../components/LiveChart.astro';

Chaque graphique ci-dessous est dessiné en direct dans cette page depuis les sources de DzGraph, avec des données
inventées. Survolez-les, prenez le clavier, passez le site en sombre : chacun suit. Chacun renvoie à la page qui dit ses
options, avec le code pour l’écrire.

## Types de séries

### Courbes

Des points reliés dans l’ordre des x ; un trou là où manque une valeur. [Sa page](../options/series-types/line/).

<LiveChart
  height={300}
  options={{
    title: { text: 'Abeilles vues par heure (inventées)' },
    xAxis: { scale: 'category', categories: ['08:00', '10:00', '12:00', '14:00', '16:00', '18:00'] },
    series: [
      { type: 'line', id: 'hiveA', name: 'Ruche A', data: [12, 30, null, 61, 44, 23] },
      { type: 'line', id: 'hiveB', name: 'Ruche B', marker: false, data: [8, 21, 39, 47, 35, 15] },
    ],
  }}
/>

### Jauge

Une valeur sur son échelle, avec graduations et zones nommées. [Sa page](../options/series-types/gauge/), où chaque
partie se règle avec des boutons.

<LiveChart
  height={340}
  options={{
    title: { text: 'Bilan du réservoir (inventé)' },
    series: [
      {
        type: 'gauge',
        id: 'balance',
        name: 'Bilan du réservoir',
        data: -1700,
        min: -2000,
        max: 2000,
        origin: 0,
        ticks: { step: 100, labels: 500 },
        thresholdsOn: 'track',
        thresholds: [
          { from: -2000, to: -1500, label: 'Froid', color: 'cold' },
          { from: -500, to: 500, label: 'Normal', color: 'calm' },
        ],
      },
    ],
  }}
/>

## Explorer

### Zoomer

Glissez sur le tracé, pincez, ou prenez les touches ; 20 000 points. [Sa page](../options/features/zoom/).

<LiveChart
  height={320}
  features={['timeAxis', 'zoom']}
  data={{ recipe: 'walk', count: 20000 }}
  options={{
    title: { text: 'Un capteur inventé : glissez sur le tracé pour zoomer' },
    xAxis: { scale: 'time', zone: 'UTC' },
    series: [{ type: 'line', id: 'sensor', name: 'Mesure', data: [] }],
  }}
/>

### Navigateur et périodes

Toute la série sous le graphique, une fenêtre à déplacer dessus, et des boutons pour les périodes courantes ; 100 000
points. [Sa page](../options/features/navigator-strip/).

<LiveChart
  height={420}
  features={['timeAxis', 'navigatorStrip', 'crosshair']}
  data={{ recipe: 'walk', count: 100000 }}
  options={{
    title: { text: 'Un capteur inventé, 100 000 mesures' },

    rangeButtons: true,
    crosshair: true,
    xAxis: { scale: 'time', zone: 'UTC' },
    series: [{ type: 'line', id: 'sensor', name: 'Mesure', data: [] }],
  }}
/>

## De droite à gauche

L’élément du graphique en arabe : les barres partent de la droite, l’axe des valeurs s’y tient, les nombres dans les
chiffres de la langue. [Le guide](../guides/theming-rtl/).

<LiveChart
  height={360}
  language="ar"
  options={{
    title: { text: 'Pots vendus (inventés)' },
    xAxis: { scale: 'category', categories: ['يناير', 'فبراير', 'مارس', 'أبريل'] },
    series: [
      { type: 'bar', id: 'plum', name: 'Prune', data: [1240, 1810, 2260, 1930] },
      { type: 'bar', id: 'quince', name: 'Coing', data: [860, 1120, 1540, 2010] },
    ],
  }}
/>
