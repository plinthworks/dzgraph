Every chart below is drawn live in this page from DzGraph's sources, with made-up data. Hover them, use the keyboard,
switch the site to dark: each follows. Each one links to the page that tells its options, with the code to write it.

## Series types

### Lines

Points joined in x order; a gap where a value is missing. [Its page](../options/series-types/line/).

  height={300}

### Gauge

One value against its scale, with ticks and named zones. [Its page](../options/series-types/gauge/), where every part
can be set with buttons.

<LiveChart
  height={340}
  options={{
    title: { text: 'Tank balance (made up)' },
    series: [
      {
        type: 'gauge',
        id: 'balance',
        name: 'Tank balance',
        data: -1700,
        min: -2000,
        max: 2000,
        origin: 0,
        ticks: { step: 100, labels: 500 },
        thresholdsOn: 'track',
        thresholds: [
          { from: -2000, to: -1500, label: 'Cold', color: 'cold' },
          { from: -500, to: 500, label: 'Normal', color: 'calm' },
        ],
      },
    ],
  }}
/>

## Exploring

### Zoom

Drag across the plot, pinch, or use the keys; 20 000 points. [Its page](../options/features/zoom/).

<LiveChart
  height={320}
  features={['timeAxis', 'zoom']}
  data={{ recipe: 'walk', count: 20000 }}
  options={{
    title: { text: 'A made-up sensor: drag across the plot to zoom' },
    xAxis: { scale: 'time', zone: 'UTC' },
    series: [{ type: 'line', id: 'sensor', name: 'Reading', data: [] }],
  }}
/>

### Navigator and ranges

The whole series under the chart, a window to move along it, and buttons for the usual ranges; 100 000 points.
[Its page](../options/features/navigator-strip/).
