The exports' defaults: the file's name, the pictures' colours, the CSV's separators.

<OptionFacts chart="exporting" />

## What it does

The chart exports itself through its methods — `exportSvg()`, `exportPng()`, `exportCsv()`, `download()`,
`print()` — and through the reader's [`menu`](../menu/). This option gives their defaults:

- `filename`: the downloaded file's name, without its extension. By default the title's letters, digits and hyphens,
  else « chart » in the chart's language.
- `theme`: `'light'` or `'dark'` for the pictures (SVG, PNG). By default they keep the screen's colours: a dark page
  exports dark.
- `csv.locale`: `true` writes semicolons between cells and a decimal comma where the chart's language writes one (as a
  French spreadsheet expects). By default the CSV is universal: commas and dots.

The exports need the [`exporting`](../../features/exporting/) feature. The option is read without it, but the methods
then do nothing and report `missing-module` at `exporting`. Something else than an object is `invalid-option` at
`exporting`; a wrong key or value `invalid-option` at `exporting.<key>`.

## Example

<CodeTabs>
<Fragment slot="ts">

```ts
import { column } from '@dzgraph/core';
import { chart, exporting } from '@dzgraph/dom';

const c = chart(
  document.getElementById('exporting')!,
  {
    title: 'Crates picked (made up)',
    exporting: { filename: 'crates', theme: 'light', csv: { locale: true } },
    series: [{ type: 'column', id: 'crates', name: 'Crates', data: [12, 19, 15, 22, 17] }],
  },
  { types: [column], features: [exporting] },
);

document.getElementById('save')!.addEventListener('click', () => void c.download('png'));
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { column, type ChartOptions } from '@dzgraph/core';
import { exporting } from '@dzgraph/dom';
import { DzChart } from '@dzgraph/angular';

@Component({
  selector: 'app-exporting',
  imports: [DzChart],
  template: `<dz-chart style="block-size: 300px" [options]="options" [types]="types" [features]="features" />`,
})
export class ExportingChart {
  readonly types = [column];
  readonly features = [exporting];
  readonly options: ChartOptions = {
    title: 'Crates picked (made up)',
    exporting: { filename: 'crates', theme: 'light', csv: { locale: true } },
    series: [{ type: 'column', id: 'crates', name: 'Crates', data: [12, 19, 15, 22, 17] }],
  };
}
```
