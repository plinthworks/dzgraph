The axis along which the x values run.

<OptionFacts chart="xAxis" />

## What it does

One axis, or a list of axes. Absent, the chart makes one, its scale guessed from the data: `'category'`
when the x values are strings, else `'linear'`. Each axis's keys have their page under [Axes](../../axis/scale/):
[`scale`](../../axis/scale/), [`min`](../../axis/min/) and [`max`](../../axis/max/),
[`ticks`](../../axis/ticks/), [`title`](../../axis/title/), [`opposite`](../../axis/opposite/),
[`reversed`](../../axis/reversed/), and the keys of one scale ([`categories`](../../axis/categories/),
[`zone`](../../axis/zone/)).

With several axes, the first is `x`, the next `x2`, `x3`… unless an axis has an [`id`](../../axis/id/); a series
names the one it is drawn against ([`xAxis`](../../series/x-axis/)). An id is shared by x and y axes: two axes may not have
the same one (`duplicate-id`).

An x axis may group its points by period or step ([`aggregate`](../../axis/aggregate/)); a value axis's keys
(`stacking`, `compare`) are refused on it (`invalid-option`). A `'time'` scale needs the
[`timeAxis`](../../features/time-axis/) feature.

Problems name the axis by its place, even when one axis is given alone: `xAxis[0]`. An axis that is not an object is
`invalid-option` at `xAxis[i]`; a key the axis's scale does not have is `unknown-option` at `xAxis[i].<key>`.

## Example

<CodeTabs>
<Fragment slot="ts">

```ts
import { line } from '@dzgraph/core';
import { chart } from '@dzgraph/dom';

chart(
  document.getElementById('x-axis')!,
  {
    xAxis: { scale: 'category', title: 'Month', categories: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'] },
    series: [{ type: 'line', id: 'visits', name: 'Visits', data: [310, 340, 420, 510, 580, 640] }],
  },
  { types: [line] },
);
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { line, type ChartOptions } from '@dzgraph/core';
import { DzChart } from '@dzgraph/angular';

@Component({
  selector: 'app-x-axis',
  imports: [DzChart],
  template: `<dz-chart style="block-size: 300px" [options]="options" [types]="types" />`,
})
export class XAxisChart {
  readonly types = [line];
  readonly options: ChartOptions = {
    xAxis: { scale: 'category', title: 'Month', categories: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'] },
    series: [{ type: 'line', id: 'visits', name: 'Visits', data: [310, 340, 420, 510, 580, 640] }],
  };
}
```
