A sentence for screen readers, after the summary the chart writes.

<OptionFacts chart="description" />

## What it does

The chart is a figure for screen readers, described by a summary it writes itself: its kind, its series and the
range of each, its x axis (« Line chart, 2 series… »). `description` adds the app's sentence after it — what the chart
is for, what to notice. It is not shown on screen. An exported SVG picture carries the same text in its `<desc>`.

A value other than a string is reported (`invalid-option` at `description`).

## Example

<CodeTabs>
<Fragment slot="ts">

```ts
import { line } from '@dzgraph/core';
import { chart } from '@dzgraph/dom';

chart(
  document.getElementById('description')!,
  {
    title: 'Visits (made up)',
    description: 'Visits doubled between January and June.',
    series: [{ type: 'line', id: 'visits', name: 'Visits', data: [310, 340, 420, 510, 580, 640] }],
  },
  { types: [line] },
);
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { line, type ChartOptions } from '@dzgraph/core';
import { DzChart } from '@dzgraph/angular';

@Component({
  selector: 'app-description',
  imports: [DzChart],
  template: `<dz-chart style="block-size: 300px" [options]="options" [types]="types" />`,
})
export class DescriptionChart {
  readonly types = [line];
  readonly options: ChartOptions = {
    title: 'Visits (made up)',
    description: 'Visits doubled between January and June.',
    series: [{ type: 'line', id: 'visits', name: 'Visits', data: [310, 340, 420, 510, 580, 640] }],
  };
}
```
