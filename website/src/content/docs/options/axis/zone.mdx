The time zone a time axis reads its instants in.

<OptionFacts axis="zone" />

## What it does

An IANA name (`'Europe/Paris'`, `'UTC'`). Ticks, labels, the tooltip and the data table read the wall clock of
that zone: a day tick sits at local midnight, even on a day of 23 or 25 hours; an hour the clock repeats gets two
ticks, an hour it skips none. Aggregation periods follow the zone's calendar.

The data's x values are instants: milliseconds since 1970 UTC, or ISO date-times **with** an offset (`…Z`,
`…+01:00`). A calendar day (`'2026-03-29'`) stands at its midnight in this zone. A date-time without an offset is never
guessed: the point is a gap, reported `ambiguous-instant` with how many. An unknown zone name is reported
(`invalid-option`) and the page's zone is used.

## Example

<CodeTabs>
<Fragment slot="ts">

```ts
import { line } from '@dzgraph/core';
import { chart, timeAxis } from '@dzgraph/dom';

chart(document.getElementById('tide')!, {
  xAxis: { scale: 'time', zone: 'Europe/Paris' },
  series: [{ type: 'line', id: 'tide', name: 'Tide (m)', data: [['2026-03-29T00:00:00Z', 1.2], ['2026-03-29T03:00:00+01:00', 3.8], ['2026-03-29', 2.1]] }],
}, { types: [line], features: [timeAxis] });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { line, type ChartOptions } from '@dzgraph/core';
import { timeAxis } from '@dzgraph/dom';
import { DzChart } from '@dzgraph/angular';

@Component({
  selector: 'app-tide',
  imports: [DzChart],
  template: `<dz-chart style="block-size: 300px" [options]="options" [types]="types" [features]="features" />`,
})
export class Tide {
  readonly types = [line];
  readonly features = [timeAxis];
  readonly options: ChartOptions = {
    xAxis: { scale: 'time', zone: 'Europe/Paris' },
    series: [{ type: 'line', id: 'tide', name: 'Tide (m)', data: [['2026-03-29T00:00:00Z', 1.2], ['2026-03-29T03:00:00+01:00', 3.8], ['2026-03-29', 2.1]] }],
  };
}
```
