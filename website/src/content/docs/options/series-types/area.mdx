## What it draws

An area is a [line](../line/) whose surface is filled down to zero, translucent, with the line on top; below zero it
fills up to zero. Its axis always holds zero. `marker` works as on a line.

`stack` piles the area on the other areas of the same stack: `true` is the stack named `default`, a string names
another. Areas pile by equal x values, a missing point counting as zero there; the value axis takes the piles in.
`stacking: 'percent'` on the y axis turns each pile into shares of its total. Stacked areas are not decimated. A
`stack` that is not a boolean or a non-empty string is `invalid-option` (`series[i].stack`), and so is a stack on a
log axis.

## Example

<CodeTabs>
<Fragment slot="ts">

```ts
import { area } from '@dzgraph/core';
import { chart } from '@dzgraph/dom';

chart(
  document.getElementById('visits')!,
  {
    xAxis: { scale: 'category', categories: ['Mon', 'Tue', 'Wed', 'Thu', 'Fri'] },
    series: [
      { type: 'area', id: 'greenhouse', name: 'Greenhouse', stack: true, data: [42, 46, 61, 58, 70] },
      { type: 'area', id: 'orchard', name: 'Orchard', stack: true, data: [12, 15, 30, 26, 41] },
    ],
  },
  { types: [area] },
);
```
