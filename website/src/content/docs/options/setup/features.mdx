## What it does

Each feature is its own import from `@dzgraph/dom`: [`timeAxis`](../../features/time-axis/), [`zoom`](../../features/zoom/), [`navigatorStrip`](../../features/navigator-strip/), [`canvas`](../../features/canvas/), [`webgl`](../../features/webgl/), [`crosshair`](../../features/crosshair/), [`compare`](../../features/compare/), [`measure`](../../features/measure/), [`selection`](../../features/selection/), [`aggregation`](../../features/aggregation/), [`drilldown`](../../features/drilldown/), [`menu`](../../features/menu/), [`exporting`](../../features/exporting/). A chart does only what its features
allow, and a page ships only the features it imports; `allFeatures` gives every one. Some bring another with them:
`navigatorStrip` brings `zoom`, `webgl` brings `canvas`, `drilldown` brings `aggregation`.

An option that needs a feature the chart was not given is not an error: the chart draws without it and reports
`missing-module`, the feature's name in the problem's detail (a time axis is then drawn linear). Without `canvas`,
every series is drawn in SVG, however many points it has.

`<dz-chart>` takes them as its `[features]` input, or once for the whole app with `provideDzGraph({ types, features })` (`@dzgraph/angular`) in `bootstrapApplication` or a route; a binding on the tag wins. The component imports none itself, so the app ships only those it names; `provideDzGraph({ types: allTypes, features: allFeatures })` gives everything. Neither: no feature.

## Example

<CodeTabs>
<Fragment slot="ts">

```ts
import { line } from '@dzgraph/core';
import { chart, navigatorStrip, timeAxis } from '@dzgraph/dom';

chart(
  document.getElementById('sensor')!,
  {
    title: { text: 'A made-up sensor, one reading a minute' },
    navigator: true,
    xAxis: { scale: 'time', zone: 'UTC' },
    series: [{ type: 'line', id: 'sensor', name: 'Reading', data: [[1767225600000, 101], [1767225660000, 99.6], [1767225720000, 100.4]] }],
  },
  { types: [line], features: [timeAxis, navigatorStrip] },
);
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { line, type ChartOptions } from '@dzgraph/core';
import { navigatorStrip, timeAxis } from '@dzgraph/dom';
import { DzChart } from '@dzgraph/angular';

@Component({
  selector: 'app-sensor',
  imports: [DzChart],
  template: `<dz-chart style="block-size: 360px" [options]="options" [types]="types" [features]="features" />`,
})
export class Sensor {
  readonly types = [line];
  readonly features = [timeAxis, navigatorStrip];
  readonly options: ChartOptions = {
    title: { text: 'A made-up sensor, one reading a minute' },
    navigator: true,
    xAxis: { scale: 'time', zone: 'UTC' },
    series: [{ type: 'line', id: 'sensor', name: 'Reading', data: [[1767225600000, 101], [1767225660000, 99.6], [1767225720000, 100.4]] }],
  };
}
```
