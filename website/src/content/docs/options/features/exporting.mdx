Export and printing: SVG, PNG and CSV, a download, print.

<OptionFacts feature="exporting" />

## What it does

It gives the chart's export methods their work, and the [`menu`](../menu/) its « Download » and « Print »
entries:

| Method | What it gives |
|---|---|
| `exportSvg(options?)` | the view as a standalone SVG document (a string) |
| `exportPng(options?)` | the view as a PNG (a promise of a `Blob`) |
| `exportCsv(options?)` | the data as CSV (a string), the rows the table shows |
| `download(format, options?)` | the browser's save of `'png'`, `'svg'` or `'csv'`, named after the title |
| `print(options?)` | the chart alone, printed in light colours; `table: true` adds its data table |

A picture is the view as on screen (the visible range, hidden series left out, the selection, the comparison) with the
title, the axes and the legend, but without the controls, the tooltip or the focus ring. Its colours are the screen's
unless `theme` asks for `'light'` or `'dark'`; `width` and `height` lay the chart out again at that size; a PNG is
drawn at `scale` device pixels per CSS pixel, at least 2 by default. The SVG carries its colours and fonts, a title and
a description. The CSV writes raw values, times in ISO 8601 with their offset, and guards cells against formulas;
`locale: true` uses the language's separators. The [`exporting`](../../chart/exporting/) option sets the defaults.

Without it, the methods give `null` or do nothing, and report `missing-module`.

## Example

<CodeTabs>
<Fragment slot="ts">

```ts
import { column } from '@dzgraph/core';
import { chart, exporting } from '@dzgraph/dom';

const c = chart(
  document.getElementById('crates')!,
  { title: { text: 'Crates picked (made up)' }, series: [{ type: 'column', id: 'crates', name: 'Crates', data: [12, 19, 15, 22, 17] }] },
  { types: [column], features: [exporting] },
);
document.getElementById('save')!.addEventListener('click', () => void c.download('png', { theme: 'light' }));
const csv = c.exportCsv();
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component, viewChild } from '@angular/core';
import { column, type ChartOptions } from '@dzgraph/core';
import { exporting } from '@dzgraph/dom';
import { DzChart } from '@dzgraph/angular';

@Component({
  selector: 'app-crates',
  imports: [DzChart],
  template: `<dz-chart style="block-size: 300px" [options]="options" [types]="types" [features]="features" />
    <button type="button" (click)="save()">Save as PNG</button>`,
})
export class Crates {
  readonly types = [column];
  readonly features = [exporting];
  readonly chart = viewChild.required(DzChart);

  async save(): Promise<void> {
    await this.chart().chart?.download('png', { theme: 'light' });
  }

  readonly options: ChartOptions = {
    title: { text: 'Crates picked (made up)' },
    series: [{ type: 'column', id: 'crates', name: 'Crates', data: [12, 19, 15, 22, 17] }],
  };
}
```
